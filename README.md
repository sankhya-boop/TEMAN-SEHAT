## Deskripsi Website
Website ini bertujuan untuk memberikan edukasi kepada masyarakat umum mengenai pentingnya pola hidup sehat, gizi seimbang, aktivitas fisik, dan pencegahan penyakit secara preventif sesuai dengan standar sumber tepercaya.

## Halaman Website
Website ini terdiri dari 5 halaman utama:
1. `index.html` (Beranda)
2. `edukasi.html` (Edukasi Gizi & Kesehatan)
3. `panduan.html` (Panduan Praktis Sehari-hari)
4. `artikel.html` (Artikel & Wawasan)
5. `tentang.html` (Tujuan Website, Tentang Kelompok & Referensi)

## Teknologi yang Digunakan
- **HTML5 Semantik** (`header`, `nav`, `main`, `section`, `article`, `footer`)
- **CSS3 Eksternal**
- **Flexbox** untuk pengaturan tata letak fleksibel
- **CSS Media Queries** untuk desain responsif (desktop, tablet, smartphone)

## Penjelasan Implementasi Teknis
- **Navigasi Konsisten:** Setiap halaman dilengkapi tautan navigasi yang menghubungkan kelima halaman secara timbal balik.
- **Responsif:** Menggunakan teknik Flexbox dan media queries pada file `style.css` agar tampilan menyesuaikan ukuran layar perangkat pengguna tanpa *horizontal scrolling* yang tidak perlu.
